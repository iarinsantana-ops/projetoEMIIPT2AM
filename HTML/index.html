Sobre o projeto

O projeto de vagas de estacionamento tem como objetivo facilitar a identificação de vagas disponíveis nos blocos, tornando o estacionamento mais organizado e prático para os usuários. Para isso, foi desenvolvido um aplicativo que permite visualizar, de forma rápida e simples, quais vagas estão livres e quais estão ocupadas. No aplicativo, as vagas são representadas por cores para facilitar a visualização. A cor verde indica que a vaga está livre e disponível para utilização, enquanto a cor vermelha indica que a vaga está ocupada. Dessa forma, o usuário consegue verificar a situação das vagas antes de se deslocar até o estacionamento, economizando tempo e evitando a procura desnecessária por um espaço disponível. O aplicativo possui uma tela de cadastro, onde o usuário pode criar sua conta, e uma tela de login, utilizada para acessar o sistema com segurança. Também existe a tela de vagas, que apresenta a situação das vagas dos blocos, indicando quais estão livres ou ocupadas. Além disso, o aplicativo conta com a tela “Sobre o Projeto”, que apresenta informações sobre a finalidade e o funcionamento do sistema. Esse projeto busca utilizar a tecnologia para solucionar um problema comum do dia a dia, proporcionando mais praticidade, organização e agilidade na utilização das vagas de estacionamento. Com uma interface simples e o uso de cores para representar a disponibilidade, o aplicativo torna a consulta das vagas mais fácil e acessível para todos os usuários.
